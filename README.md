# Simulated Linux Terminal — Free Online Tool

**Simulated Linux Terminal.** Learn real bash with zero risk: a virtual filesystem, 45+ commands, pipes (ls | grep), chmod permissions, SSH to a simulated remote machine and 5 guided lessons. 100% in your browser. No sign-up, no ads, 100% client-side.

🌐 **Demo en vivo / Live demo:** [miguelacm.es/tools/linux-terminal](https://miguelacm.es/tools/linux-terminal)

## ✨ Features

- **Real bash:** ls -la, cat, touch, mkdir -p, rm -r, cp, mv, grep, head, tail, wc, sort, chmod 755, export, history, man and sudo on a virtual filesystem.
- **SSH and networking:** ssh opens a simulated remote machine in a new tab with its own disk; ping, ifconfig, traceroute, curl, wget and apt install are simulated.
- **Pipes and lessons:** Real pipes like ls | grep and cat file | head -n 5, plus 5 self-assessed lessons with hints.

## 🚀 Quick start

```bash
git clone https://github.com/m-a-c-m/LinuxTerminal.git
cd LinuxTerminal
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Environment variables (optional)

```env
NEXT_PUBLIC_SITE_URL=https://miguelacm.es/tools/linux-terminal
NEXT_PUBLIC_EMBED_URL=https://miguelacm.es/embed/linux-terminal
```
